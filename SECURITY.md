# Security Policy

## Supported Versions

Code CAD Studio is currently in pre-release (`v0.1.0-alpha`). Security fixes are
applied to the latest `main` branch and included in upcoming alpha releases.

## Trust & Threat Model

Code CAD Studio is designed primarily as a **local-first desktop application**
for authoring and previewing parametric `build123d` Python CAD models on a
single workstation:

- **Arbitrary Python Execution by Design:** Opening or rendering a model library
  executes the `.py` scripts inside that library using your configured Python
  interpreter (`worker/worker.py`). **Only open model libraries from sources you
  trust**, just as you would when running any local Python script.
- **Localhost HTTP/SSE Hardening:**
  - The Go server binds to `localhost` by default and enforces a strict `Host`
    allowlist (`localhost`, `127.0.0.1`, `[::1]`, `wails.localhost`), cross-site
    `Origin` / `Sec-Fetch-Site` rejection on mutating requests, `Content-Type:
    application/json` checks, a 2 MiB JSON request body limit, and a strict
    `Content-Security-Policy`.
  - The internal Python worker (`worker/worker.py`) binds to `127.0.0.1` and
    requires a per-launch 256-bit `Authorization: Bearer` token generated by the
    Go supervisor (`CODE_CAD_WORKER_TOKEN`) plus loopback `Host` validation.
  - Desktop helper endpoints (`/api/desktop/open-editor`, `reveal-file`,
    `open-slicer`) validate symlink-resolved paths against configured library
    roots and export directories and execute commands directly without a shell.
  - Starter archive downloads (`internal/setup`) enforce HTTPS (outside local
    loopback tests), host allowlisting across redirects, optional SHA-256
    verification, decompression entry/size limits, and symlink checks.
- **Server / Docker Mode Caveats (`-tags server`):**
  - Server mode (`WAILS_SERVER_HOST=0.0.0.0` in Docker or custom host binds)
    does **not** implement multi-user authentication or authorization and executes
    model Python scripts on the server host.
  - Do **not** expose Code CAD Studio server mode directly to the public internet
    or untrusted networks without placing it behind an authenticating reverse
    proxy (e.g., TLS + SSO/basic auth) and isolating untrusted model files.
  - When serving from a non-loopback hostname via a reverse proxy, set
    `CODE_CAD_ALLOWED_HOSTS` explicitly rather than disabling host checks.

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately rather than opening a
public GitHub issue:

1. Use GitHub's **Private Vulnerability Reporting** ("Security" tab -> "Report a
   vulnerability") on `https://github.com/ltcovalt/code-cad-studio`, or
2. Contact the maintainer directly via the email listed in the repository commit
   history / GitHub profile.

Please include:
- A clear description of the vulnerability and its potential impact
- Step-by-step reproduction instructions or a minimal proof of concept
- Affected OS, Go/Python versions, and build mode (`desktop` vs. `-tags server`)

You can expect an acknowledgment within 72 hours and coordinated disclosure once
a fix is available.
