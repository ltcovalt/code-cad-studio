LGPL-licensed native libraries inside the desktop application binary. Instead,
the user (or the optional onboarding installer / Docker server image) provisions
an external Python virtual environment containing:

- build123d (>=0.8,<1.0)
  License: Apache License 2.0
  https://github.com/gumyr/build123d

  License: LGPL-2.1-only with OCCT Exception 1.0 (Open CASCADE Technology)
  https://github.com/CadQuery/OCP
